# Social Network Recommendation System

## Overview
This project simulates core social media recommendation features using Python and JSON datasets.

## Features
- User Connection Analysis
- People You May Know Recommendations
- Pages You Might Like Recommendations
- Data Cleaning and Structuring
- JSON Data Processing

## Technologies Used
- Python
- JSON
- Jupyter Notebook
- Data Structures and Algorithms

## Project Modules

### 1. Introduction
Loads and displays user and page information.

### 2. Data Cleaning and Structuring
Processes raw JSON data into a clean format suitable for analysis.

### 3. People You May Know
Recommends potential friends based on mutual connections.

### 4. Pages You Might Like
Suggests pages based on shared interests among users.

## Sample Output

People You May Know for User 1: [4, 5]

Pages You Might Like for User 1: [102, 104]
